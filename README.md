# Yaksh Jakharia | Full-Stack MERN Developer Portfolio

A modern, responsive portfolio website built with **React.js** and **Tailwind CSS**. This project showcases a clean UI/UX, smooth navigation, and a deep focus on the MERN stack (MongoDB, Express, React, Node.js).



## 🛠 Tech Stack

* **Frontend:** React.js
* **Styling:** Tailwind CSS (Utility-first CSS)
* **Icons:** Lucide React
* **Deployment:** Optimized for Vercel/Netlify

## Features

- **Responsive Design:** Optimized for Desktop, Tablet, and Mobile.
- **Project Showcase:** Detailed cards for 6 specialized MERN projects.
- **Modern UI:** Glassmorphism effects, gradient text, and smooth scroll transitions.
- **Contact Integration:** Directly linked social profiles and a functional-ready contact form.
- **Performance:** Minimal dependencies for lightning-fast load times.
